# Own structure models

AlphaFold 3 models of characterized LPMOs that no public structure or sequence database holds
in the right form (see `../local_models.csv` for the proteins and the reasons). Each folder
holds the top-ranked model (`*_model_0.cif`), the AlphaFold Server job request and the model's
confidence summary.

Made with AlphaFold Server (Abramson et al., Nature 2024, doi:10.1038/s41586-024-07487-w).
