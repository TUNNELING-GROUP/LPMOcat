# Data licence

The catalogue's data — the database, the pipeline outputs, the data bundle and every file the
website offers for download — are licensed under the
[Creative Commons Attribution 4.0 International licence (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/).
You may share and adapt them for any purpose, provided you give appropriate credit (cite
LPMOcat) and indicate if changes were made.

The data are built from public resources, which keep their own terms: RCSB PDB (CC0),
AlphaFold DB (CC BY 4.0), UniProt (CC BY 4.0), InterPro (CC0), BRENDA (CC BY 4.0), CAZy,
CAZyme3D, NCBI Taxonomy, SIFTS and Europe PMC. Please also cite the resources you rely on;
the About page of the website lists them with their references.

The three structure models in `lpmocat_pipeline/curation/models/` were made with AlphaFold
Server and are shared under the
[AlphaFold Server Output Terms of Use](https://alphafoldserver.com/output-terms): for
non-commercial use only, with credit to AlphaFold Server (Abramson et al., Nature 2024,
doi:10.1038/s41586-024-07487-w).
